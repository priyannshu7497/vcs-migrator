Project: VCS Migrator
VCS Migrator is a web-based solution that enables migration of repositories
and related metadata across different version control providers such as
GitHub, GitLab, and Bitbucket.

✨ Features
- Manual and scheduled repository migration
- Selective migration of branches, tags, PRs, issues, and users
- Support for GitHub, GitLab, and Bitbucket
- Asynchronous job processing
- Migration status tracking and logs

🏗️ Architecture Overview
The system consists of a web UI, backend API, background workers, and
external VCS provider integrations.
